ФОРМА ЗАПИСИ НА ВЕБИНАР: сайт на GitHub Pages + заявки в Telegram

Как это работает:
  форма (GitHub Pages) -> воркер Cloudflare -> бот -> личное сообщение Татьяне в Telegram
Токен бота хранится только в воркере. В файле сайта его нет, поэтому он не виден посетителям.

Содержимое папки:
  site/index.html    сайт с формой (его выкладывать на GitHub Pages)
  worker/worker.js   код воркера Cloudflare

ШАГ 1. Воркер Cloudflare (бесплатно)
  1. Зарегистрируйтесь на cloudflare.com.
  2. Workers & Pages -> Create -> Create Worker. Название, например, webinar-form -> Deploy.
  3. Нажмите Edit code, удалите весь код, вставьте содержимое worker/worker.js -> Deploy.
  4. Settings -> Variables and Secrets -> Add. Добавьте три переменные:
       BOT_TOKEN       тип Secret, токен бота от @BotFather
       CHAT_ID         тип Text, числовой Telegram-ID Татьяны (несколько ID через запятую)
       ALLOWED_ORIGIN  тип Text, адрес сайта БЕЗ слеша и БЕЗ пути, например https://username.github.io
     Нажмите Deploy, чтобы сохранить.
  5. Скопируйте адрес воркера, он вида https://webinar-form.ИМЯ.workers.dev
  6. ВАЖНО: Татьяна должна один раз открыть бота и нажать /start. Иначе бот не сможет писать ей первым.

ШАГ 2. Вставить адрес воркера в форму
  Откройте site/index.html в блокноте, найдите строку
       var ENDPOINT = "https://ВАШ-ВОРКЕР.workers.dev";
  и замените адрес на адрес вашего воркера (шаг 1, пункт 5). Сохраните.
  Пока адрес не вставлен, форма работает в запасном режиме: открывает Telegram с готовым сообщением.

ШАГ 3. GitHub Pages
  1. На github.com создайте репозиторий (Public), например webinar.
  2. Add file -> Upload files: загрузите index.html в КОРЕНЬ репозитория -> Commit.
  3. Settings -> Pages -> Source: Deploy from a branch -> Branch: main, папка /(root) -> Save.
  4. Через 1-2 минуты сайт откроется по адресу https://username.github.io/webinar/
  (username - ваш логин на GitHub, webinar - название репозитория).

ПРОВЕРКА
  Заполните форму на опубликованном сайте. Татьяне в Telegram должно прийти сообщение от бота
  «Новая заявка на вебинар». Если сообщения нет, проверьте: /start у бота, CHAT_ID (число),
  ALLOWED_ORIGIN (точно как адрес сайта, https://, без / на конце), токен.
  Если автоматическая отправка не прошла, форма сама предложит отправить данные вручную через Telegram.

ОБРАТИТЕ ВНИМАНИЕ
  - Адреса *.workers.dev у некоторых российских провайдеров открываются нестабильно. Тогда лучше
    привязать к воркеру собственный домен (в Cloudflare: Workers -> Settings -> Domains & Routes).
  - Заявки содержат персональные данные: они проходят через GitHub (страница), Cloudflare (воркер) и Telegram.
    Для работы с гражданами РФ это нужно согласовать с юристом (закон о персональных данных).
    Ссылку на политику конфиденциальности добавьте рядом с галочкой согласия.
  - Защита от спама: скрытое поле-ловушка и проверка адреса сайта. От целенаправленного спама
    помогает Cloudflare Turnstile (бесплатная капча); при необходимости добавим.
